# The Fixture Shelf

Committed, anonymised byte fixtures — the [GATE] criteria run on these inside
`cargo test` and therefore inside the Sentinel, so the 1.2-era format deltas
stay regression-protected forever **without a byte of private save data in
the repo**. The Sentinel never sees a real save file.

| Fixture | Provenance | Guards |
|---|---|---|
| `cipher-header.bin` | REAL capture — first 64 raw bytes of the investor's `transfer.gst` (2026-08-16), anonymised by truncation: seed + magic + block header + version + mod + expansion + tab count, nothing item- or character-derived follows | Cipher byte-for-byte round-trip vs the proven spike |
| `item-v11-real.bin` + `.expected.json` | REAL capture — one item's full field set from the investor's `transfer.gst`, re-encrypted under a fresh synthetic seed (no surrounding save data, no original seed) | The full item field-set round-trip (delta #2's field order) |
| `item-v11-trap.bin` | synthetic | The v11 four-trailing-int32 skip; trap ints `[7,9,7,9]` are the known-wrong x/y read if the skip is missed |
| `stash-tab-v11.bin` | synthetic | The 20-byte v11 tab trailer (delta #3) |
| `transfer-v11.gst` | synthetic | Full warehouse walk, per-tab geometry, expansion byte 7 (delta #4) |
| `player-v8-inv11.gdc` | synthetic | Per-BLOCK version gating (delta #1): file v8, inventory + stash v11 |
| `player-corrupt.gdc` | synthetic | The flagged-not-fatal path |

## The forge

Synthetic fixtures are regenerated by the test-only Scribe (the cipher's
inverse — the shipped app never encrypts anything):

```sh
cargo test -- --ignored forge_fixtures
```

With `SMUGGLERS_BENCH_SAVE_ROOT` set to a real save root, the forge also
re-captures the two REAL fixtures. Only re-capture deliberately: the
`.expected.json` values change with the investor's live stash, and the point
of committing them is regression, not freshness.
